# skitrip — полная стоимость горнолыжной недели

Для каждого ледникового курорта Италии, Франции и Австрии и каждой субботы заезда за сезон считает:

**перелёт TLL⇄аэропорт на всю группу + машина и топливо + жильё на 7 ночей + ски-пассы на 6 дней**

Группа по умолчанию: 2 взрослых + ребёнок 6 лет (`config.yaml`).

## Откуда данные

| Слой | Источник | Как |
|---|---|---|
| Перелёты | Google Flights | `fast-flights`, цена туда-обратно сразу на 2 взрослых + 1 ребёнка, лучший из аэропортов курорта |
| Перелёты | Ryanair | публичный API тарифов, (туда + обратно) × пассажиры, без багажа; берётся дешевле из Google и Ryanair. Wizz Air закрыт проверкой «вы человек?» — его рейсы видны только через Google |
| Перелёты | Ryanair, 2 билета | самостоятельная пересадка: origin → хаб → аэропорт курорта в один день, запас ≥ 3 ч (`self_transfer`); ищется по всем хабам Ryanair |
| Города вылета | `config.yaml → trip.origins` | Таллин и Рига; к Риге добавляется автобус на всю группу (150 €) |
| Жильё | Airbnb | `pyairbnb`, поиск в прямоугольнике вокруг курорта, целиком жильё, 2+1 гостя; в расчёт идёт 25-й перцентиль цены за неделю |
| Ски-пассы | `resorts.yaml` | цены 2026/27 по периодам сезона + правила для детей (год рождения в Австрии, возраст во Франции) |
| Снег | Open-Meteo | глубина на высоте верхней станции, свежий снег за 7 дней и прогноз |
| Трансфер | `config.yaml` | аренда машины на неделю + €/км × расстояние × 2 |

Booking.com не даёт открытого API, а Hotellook (Travelpayouts) отключён с 20.10.2025, поэтому жильё — только Airbnb.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python -m skitrip passes                        # ски-пассы на группу, без сети
python -m skitrip run --resorts tignes --weeks 2 --limit 6   # пробный прогон
python -m skitrip run --open                    # всё: ~12 курортов × 18 недель, 30–60 мин из-за пауз
python -m skitrip report --open                 # пересобрать отчёт из базы
python -m skitrip demo --open                   # отчёт на синтетике, чтобы посмотреть вид
```

Флаги `run`: `--resorts ID…`, `--weeks N`, `--start YYYY-MM-DD`, `--skip-flights`, `--skip-lodging`, `--skip-snow`, `--limit N`.

История цен копится в `data/prices.sqlite`; при падении цены перелёта на `alerts.drop_pct`% строка в логе помечается «↓ было …». Отчёт — `data/report.html`, один файл без внешних зависимостей.

## Что стоит поправить руками

- `config.yaml → party.children[].birth_date` — точная дата рождения. В Австрии льгота считается по году рождения, в Cervinia — по дате (после 24.11.2020 бесплатно), во Франции — по возрасту в день катания.
- `resorts.yaml → status`. `verified_2026_27` — цены сезона 26/27 из источника в поле `source`. `from_2025_26` (Stubai, Val Senales) и `estimate` (Pitztal, Val Thorens junior, Les 2 Alpes child, Alpe d'Huez child) стоит сверить на сайтах курортов перед бронированием.
- Расстояния до аэропортов и стоимость машины — оценки.

## Ограничения

- У Google Flights и Airbnb нет публичных API: библиотеки повторяют запросы сайтов и ломаются, когда сайт меняется. Перелёты останавливаются после 4 ошибок подряд.
- С IP дата-центров (GitHub Actions, облако) оба сервиса блокируют чаще — запускайте с домашнего компьютера или задайте `FLIGHTS_PROXY`.
- Цена Airbnb в выдаче — до налога на туриста в ряде стран; цена Google — минимальная, без багажа (ски-багаж — `costs.ski_bag_per_person_rt`).
